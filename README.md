# Sonny Scaffolds website restoration

Historical restoration of the July 2006 Sonny Scaffolds website from Internet Archive captures and recovered original assets.

See `RESTORATION-NOTES.txt` for provenance and reconstructed elements.

## GitHub Pages

This repository is prepared for GitHub Pages at `sonnyscaffolds.com`. `index.html` is a copy of the original `index.htm` so the site loads correctly at the domain root; the original filename is retained for historical internal links.
